# 🌐 تطبيق مترجم الذكاء الاصطناعي (AI Translator)
### ترجمة فورية بين العربية والإنجليزية والفرنسية مع الكاميرا والذكاء الاصطناعي وخطة تحقيق الدخل

---

## 📱 مميزات التطبيق
1. **الترجمة الفورية للنصوص:**
   - دعم كامل للغات الأربع: **العربية 🇪🇬🇸🇦، الإنجليزية 🇬🇧🇺🇸، الفرنسية 🇫🇷، والألمانية 🇩🇪**.
   - كشف تلقائي للغة وتبديل سريع بين اللغات.
   - ترجمة فورية بالذكاء الاصطناعي (Gemini 3.5 Flash) مع بديل محلي مجاني.
   - نطق صوتي للنص (Text-to-Speech) باللكنة الأصلية.
   - نسخ فوري ومشاركة على الواتساب.

2. **الترجمة بالكاميرا والصور (AI Vision OCR):**
   - فتح كاميرا الهاتف مباشرة والتقاط صور المستندات واللافتات والكتب.
   - إمكانية رفع صورة من الاستوديو/معرض الصور.
   - استخراج النص المكتوب وترجمته في ثوانٍ.

3. **ترجمة ملفات الـ PDF والمستندات الكاملة (جديد 📄):**
   - رفع أي ملف PDF (كتب، أبحاث، عقود، سيرة ذاتية).
   - قراءة المحتوى بالذكاء الاصطناعي وترجمته بالكامل وتنزيل الترجمة كملف نصي (TXT).
   - مدمجة بنظام إعلانات المكافأة عالي العائد المالي (High-eCPM).

4. **دليل عبارات السفر والمحادثة (Phrasebook ✈️):**
   - جمل جاهزة للسفر والمطارات والفنادق والمطاعم والطوارئ لنطقها واستخدامها فوراً لزيادة وقت بقاء الزائر.

5. **كلمة اليوم الذكية (Word of the Day 💡):**
   - كلمة جديدة يومياً باللغات الأربع مع أمثلة ونطق صوتي لجذب الزوار للموقع يومياً.

6. **تطبيق ويب تقدمي (PWA):**
   - يعمل على الموبايل والكمبيوتر كأنه تطبيق موبايل رسمي.
   - زر **"تثبيت التطبيق"** يظهر على الهاتف لتثبيته على الشاشة الرئيسية بدون الحاجة لدفع رسوم متجر جوجل بلاي (25$) أو أبل (99$).

7. **خطة تحقيق الدخل والربح الأقصى:**
   - مساحات إعلانية مجهزة لـ **Google AdSense**.
   - إعلانات مكافأة قبل تنزيل ملفات الـ PDF المترجمة.
   - قسم للتسويق بالعمولة (Affiliate) لحجوزات الفنادق وشرائح السفر eSIM لزيادة الأرباح بالدولار.

## 🚀 كيفية تشغيل التطبيق وتجربته الآن
1. يمكنك ببساطة فتح ملف `index.html` في أي متصفح (مثل Chrome أو Edge أو Safari).
2. أو تشغيل سيرفر محلي سريع عبر كتابة الأمر التالي في موجه الأوامر داخل هذا المجلد:
   ```bash
   npx serve .
   ```

## 🔑 كيفية تفعيل الذكاء الاصطناعي المجاني (Gemini API)
التطبيق يعمل مباشرة للترجمة النصية بدون أي إعدادات! ولكن لتفعيل ميزة تصوير الكاميرا بالذكاء الاصطناعي بأعلى دقة:
1. ادخل مجاناً بحساب جوجل على: **[Google AI Studio](https://aistudio.google.com/app/apikey)**
2. اضغط على **Create API Key**.
3. افتح التطبيق، واضغط على أيقونة **الإعدادات (⚙️)** من أعلى الشاشة.
4. الصق المفتاح واضغط **"حفظ المفتاح"**.

## 🌐 كيفية رفع التطبيق على الإنترنت مجاناً 100% (0 جنيه / 0 دولار)
اختر أياً من الطرق المجانية التالية:
### الطريقة الأولى (الأسهل والأسرع): منصة Vercel أو Netlify
1. قم بإنشاء حساب مجاني على [vercel.com](https://vercel.com) أو [netlify.com](https://netlify.com).
2. اسحب مجلد المشروع `Translate` وأفلته في الموقع (Drag & Drop).
3. سيعطيك فوراً رابطاً عالمياً سريعاً جداً (مثل: `my-translator.vercel.app`) يمكنك إرساله لأي شخص!

### الطريقة الثانية: GitHub Pages
1. ارفع ملفات المشروع على مستودع (Repository) في GitHub.
2. من إعدادات المستودع (Settings) ⬅️ ادخل على **Pages** ⬅️ اختر `main branch` واحفظ.
3. سيصبح موقعك متاحاً مجاناً للجميع مدى الحياة.

## 💰 كيف تبدأ بجني الأرباح؟
1. **Google AdSense:** سجل حساباً مجانياً على Google AdSense، وضع معرف الناشر الخاص بك في نافذة الإعدادات داخل التطبيق.
2. **الاشتراكات المباشرة:** ضع رقم هاتفك (فودافون كاش / إنستاباي) في الإعدادات، وسيظهر للراغبين في فتح ترجمات غير محدودة.
3. **نشر التطبيق:** شارك رابط تطبيقك في مجموعات الترجمة، والطلبة، ومسافري السياحة، ومجموعات تعلم اللغات.
